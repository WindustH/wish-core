Generate video or audio into Wish session blobs. May incur charges.

  wish videogen --list-providers
  wish videogen --json '{"prompt":"A quiet coastal sunrise","provider":"service-id"}'
  wish audiogen --list-providers
  wish audiogen --json '{"kind":"speech","prompt":"Hello","options":{"voice":"voice-id"}}'
  wish audiogen --json '{"kind":"music","prompt":"Gentle piano","options":{"duration":10,"instrumental":true}}'
  wish videogen --json '{"action":"status","job_id":"returned-id"}'
  wish videogen --json '{"action":"list_jobs"}'

Use --schema for the full schema. Provider is optional; configuration order selects
the first enabled service supporting the requested kind. Explicit selection never
fails over. Status resumes polling and downloads, including after server restart;
it never submits another generation. Paths are returned only for stored artifacts.
If outcome_unknown is returned, do not automatically repeat the paid request.
